# Chess

Command-line chess game built in Ruby with an object-oriented architecture and complete chess game logic.

This project focuses on game state management, piece movement validation and rule implementation while practicing software design and object-oriented programming principles.

## Features

- Full chess board implementation
- Legal piece movement validation
- Turn-based gameplay
- Check and checkmate detection
- Castling support
- En passant support
- Pawn promotion
- Object-oriented architecture
- Terminal-based interface

## Tech Stack

- Ruby

## Installation

Clone the repository:

```bash
git clone https://github.com/bachatron/chess.git
cd chess
```

Run the game:

```bash
ruby main.rb
```

## Project Structure

The application is organized into separate classes responsible for:

- Board management
- Piece behavior
- Move validation
- Game state handling
- Player turns
- Rule enforcement
